## 담당 기능

### 3. 방문 코스 _ 소선웅
- 부스를 선택하면 방문 코스에 즉시 추가합니다.
- 같은 부스를 여러 번 추가할 수 있으며, 방문 순서대로 이름·위치·실내/야외 정보를 표시합니다.
- 각 방문 행의 `삭제` 버튼은 해당 순서의 방문 한 번만 제거합니다. `코스 전체 초기화`는 방문 코스를 모두 비웁니다.
- 선택한 방문 코스를 `course_df`로 만들며, 같은 부스를 여러 번 담으면 DataFrame에도 순서대로 중복 행이 들어갑니다.
- 방문 코스는 Streamlit 세션 동안 유지됩니다. 브라우저 세션을 새로 시작했을 때 복원되는 영구 저장 기능은 없습니다.

## 3번 기능의 데이터와 연결

- 데이터 파일: `booths.csv`
- 사용하는 실제 컬럼: `id`, `name`, `category`, `location`, `indoor`, `description`
- 현재는 전체 데이터 `df`에서 부스를 선택합니다. 검색 기능이 연결되면 `course_source_df = df`를 실제 검색 결과 DataFrame으로 변경합니다.
- 이미 코스에 담은 부스 정보는 전체 원본 `df`에서 조회하므로, 검색 조건이 바뀌어도 코스는 유지됩니다.
- 5번 기능은 3번 기능 아래에서 `course_df`를 사용합니다. 4번 스탬프의 방문 완료 횟수는 이 코스의 방문 예정 횟수와 별개입니다.

## 예외 처리 및 확인 사항

- CSV 파일 없음·빈 파일·형식 오류·인코딩 오류·접근 오류를 안내합니다.
- 필요한 컬럼 누락, 선택 데이터의 ID 누락·중복, 부스 이름 누락을 안내합니다.
- `indoor` 값이 잘못된 경우 화면에 `정보 없음`으로 표시합니다.
- 코스가 비어 있을 때 안내 문구를 표시합니다.
- 직접 확인: 선택 즉시 추가, 같은 부스 재선택, 개별 삭제, 전체 초기화의 기본 동작을 확인했습니다.
- 통합 후 확인: 검색 조건 변경 시 선택창과 기존 코스, 중복 방문 행의 CSV 저장, 스탬프 기능과의 구분을 다시 확인합니다.

## 기능

### 🎲 랜덤 부스 추천

조건을 골라 두면, 그 조건에 맞는 부스 중 한 곳을 무작위로 골라 보여 줍니다.
어디부터 가 볼지 고민될 때 쓰는 기능입니다.

**조건 고르기**

- **카테고리**: 체험 · 놀이 · 전시 · 공연 · 먹거리 · 쇼핑 중에서 여러 개를 고를 수 있습니다.
  아무것도 고르지 않으면 전체 카테고리를 대상으로 합니다.
- **실내/실외**: `상관없음` · `실내` · `실외` 중에서 하나를 고릅니다.

조건을 바꿀 때마다 해당하는 부스가 몇 곳인지 바로 아래에 표시됩니다.

**추천받기**

`랜덤으로 추천받기` 버튼을 누르면 조건에 맞는 부스 한 곳이 뽑히고,
이름 · 소개 · 카테고리 · 실내/실외 · 위치를 함께 보여 줍니다.
같은 조건으로 버튼을 다시 누르면 다른 부스가 뽑힐 수 있습니다.
조건에 맞는 부스가 한 곳도 없으면 안내 메시지가 뜹니다.

## 변경 사항

- `app.py`
  - `booths.csv`를 pandas로 읽어 오도록 했습니다. `@st.cache_data`를 붙여
    화면이 새로 그려질 때마다 파일을 다시 읽지 않습니다.
  - 카테고리 다중 선택(`st.multiselect`)과 실내/실외 선택(`st.radio`) UI를 넣고,
    고른 조건으로 부스 목록을 걸러 내도록 했습니다.
  - 걸러진 목록에서 `DataFrame.sample(1)`로 한 곳을 뽑는 추천 버튼을 넣었습니다.
  - 뽑은 부스를 `st.session_state`에 담아 두어, 조건을 다시 건드려도
    추천 결과가 화면에서 사라지지 않게 했습니다.
  - 조건에 맞는 부스가 없을 때는 경고 메시지를 띄우고 이전 추천 결과를 지웁니다.
- `README.md`: 기능 설명과 변경 사항을 적었습니다.
