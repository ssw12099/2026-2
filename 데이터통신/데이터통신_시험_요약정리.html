데이터 통신의 기본 언어

데이터는 전달하려는 내용이고, 통신은 그 내용을 두 장치 사이에서 주고받는 일이다. 같은 선으로 연결해도 서로 약속이 다르면 내용을 해석할 수 없다. 이 약속이 프로토콜이다.

문자·숫자·화상·음성·영상도 비트 패턴으로 표현한다. 1비트(bit)는 0 또는 1 한 자리, 1바이트(byte)는 8비트다. 기본 ASCII는 7비트, 확장 ASCII는 8비트다. 화상은 화소(pixel)들의 모음이며, 화소 수와 화소당 비트 수가 커지면 필요한 데이터도 늘어난다.

네트워크 구조와 연결 수

이번 단원에서 배우는 것 · 토폴로지를 그림 없이 설명한다 / 그물형 링크 수를 계산한다

네트워크는 통신 링크로 연결된 장치들의 모음이다. 토폴로지는 그 장치와 선을 어떻게 배치했는지를 뜻한다. 전용선을 쓰는지, 하나의 선을 여럿이 공유하는지도 구별해야 한다.

구조연결 방식장점 / 취약점
완전 그물형 Mesh모든 장치 쌍을 전용 링크로 연결고장 분리·보안에 유리 / 배선·포트가 많음
성형 Star모든 단말이 중앙 허브에 연결설치·변경 쉬움 / 중앙 허브 고장은 전체에 영향
버스형 Bus주 케이블에 탭·드롭 라인으로 접속케이블 적음 / 중추 케이블 고장과 결함 분리에 취약
링형 Ring각 장치가 양옆 장치와 연결; 중계기 포함설치·변경 용이 / 단일 단방향 링 단절에 취약
★★★ 제작자 선정 학습 핵심
완전 그물형: 링크 수 = n(n−1)/2, 장치 하나의 포트 = n−1.
각 장치에서 n−1개씩 세면 같은 선을 양쪽에서 두 번 세므로 2로 나눈다.

이해를 위한 예시 6대라면 6×5÷2=15링크, 각 장치에는 5포트가 필요하다. 6대에서 7대로 늘릴 때 기존 6대와 새 장치를 연결하므로 새 선 6개를 더한다.

구별핵심
점-대-점 / 다중점두 장치가 링크 전용 / 3개 이상이 링크 공유
LAN / WAN건물·캠퍼스 등 근거리 자원 공유 / 넓은 지리적 영역 연결
internet / Internet여러 네트워크의 상호 연결 / 전 세계 공용 인터넷
점-대-점 WAN / 교환형 WAN전용 연결 / 여러 연결 장치를 거치는 네트워크

인터넷은 소비자 네트워크, 제공자 네트워크, 백본으로 연결된다. 백본끼리는 대등점(peering point)에서 연결한다. 인터넷 접속에는 전화망(전화접속·DSL), 케이블망, 무선망, ISP 직접 접속 등이 있다. 네트워크는 성능(처리율·지연), 신뢰성(고장·복구), 보안으로 평가한다.

헷갈림 바로잡기
완전 그물형의 “전체 링크 수”와 “장치 하나의 포트 수”를 바꾸지 않는다. 성형의 단말 선 하나 고장과 중앙 허브 고장도 영향 범위가 다르다. 이중 링은 단일 링의 고장 문제를 완화하는 방법이다.

계층화와 TCP/IP·OSI

이번 단원에서 배우는 것 · 계층별 역할과 데이터 단위를 연결한다 / 장치별 계층을 구별한다

큰 일을 단계로 나누듯 통신도 계층마다 임무를 나눈다. 이해를 위한 예시: 편지 내용 작성, 봉투 포장, 실제 운반을 따로 맡는 것과 비슷하다. 상대편 같은 계층끼리 이야기하는 것은 논리적 연결이고, 실제 신호는 물리층을 거친다.

TCP/IP 5계층 (위→아래)책임데이터 단위
응용층응용 간 메시지 교환·서비스메시지
전송층응용에 종단 간 전송 서비스 제공세그먼트 / 사용자 데이터그램
네트워크층호스트 간 전달·라우터의 경로 선택데이터그램
데이터 링크층인접 노드 사이 링크로 프레임 전달프레임
물리층매체를 따라 비트 전달비트
이해를 위한 흐름
송신: 메시지 → 전송층 패킷 → 네트워크 데이터그램 → 프레임 → 비트
수신: 반대 순서로 상위 계층에 내용을 전달한다.

양방향 통신의 계층은 보내기/받기, 암호화/복호화처럼 상반되는 작업을 수행할 수 있어야 한다. 양쪽의 대응하는 계층은 같은 종류의 객체를 다룬다. 서로 다른 모든 계층의 객체가 같다는 뜻은 아니다.

장치 / 모델강의 기준
호스트TCP/IP 5계층 모두
라우터물리·데이터 링크·네트워크의 3계층
링크층 스위치물리·데이터 링크의 2계층
OSI 7계층물리 → 데이터 링크 → 네트워크 → 전송 → 세션 → 표현 → 응용
OSI와 TCP/IP 비교TCP/IP 5계층에는 세션·표현이 별도 계층으로 없음

강의는 응용·전송·네트워크층의 책임을 종단-대-종단, 데이터 링크·물리층의 책임을 홉-대-홉으로 구분한다. OSI 모델이 널리 대체하지 못한 이유로 TCP/IP의 선점, 일부 계층 정의와 전환 완성도 부족을 제시한다.

헷갈림 바로잡기

신호는 이동하면서 작아지거나, 모양이 변하거나, 원치 않는 신호가 섞일 수 있다. 전송률을 높이고 싶어도 대역폭·준위 수·잡음이 허용하는 한계가 있다.

전력비 계산
dB=10log₁₀(P₂/P₁). 출력이 작으면 음수, 크면 양수.
이해를 위한 예시: 1/10배 → −10dB, 10배 → +10dB, 1/2배 → 약 −3dB.
SNR=평균 신호 전력/평균 잡음 전력, SNRdB=10log₁₀(SNR).
공식전제와 변수읽는 법
R=2B log₂L나이퀴스트; 잡음 없는 채널, B: Hz, L: 준위 수준위가 2ᵇ이면 log₂L=b

이해를 위한 계산 B=1MHz, SNR=63이면 C=10⁶×log₂64=6Mbps이다. 이 상한보다 낮게 4Mbps를 목표로 정하면 4×10⁶=2×10⁶×log₂L에서 L=4다. 두 공식을 함께 써도 섀넌 한계를 넘어서는 전송을 보장할 수 없다.

최소 준위 선택 B=20kHz, 목표 265kbps이면 log₂L=6.625, L≈98.7. 강의처럼 2의 거듭제곱 준위를 택할 때 목표를 만족하려면 128준위(280kbps)를 선택한다. 64준위(240kbps)는 부족하다.

이해를 위한 예시: 기차 전체가 역을 빠져나오는 시간과 첫 칸이 다음 역까지 달리는 시간은 다르다. 데이터도 모든 비트를 선에 밀어 넣는 시간과 신호가 거리를 이동하는 시간이 따로 있다.

계산 대상공식영향을 주는 것

디지털 변환과 PCM

이번 단원에서 배우는 것 · 세 가지 디지털 변환 기술을 구별한다 / 표본화 계산을 한다

0과 1이라는 데이터 자체가 전선의 전압은 아니다. 데이터에 맞는 신호를 만드는 작업이 필요하다. 반대로 연속적인 소리를 디지털로 저장하려면 일정 간격으로 값을 읽고 숫자로 바꿔야 한다.

기술무엇을 하는가핵심 차이
회선 부호화디지털 데이터 → 디지털 신호디지털 전송에 필수
블록 부호화m비트 → 더 긴 n비트 코드; mB/nB여분의 비트로 동기화·검출 등을 도움
스크램블링(뒤섞기)기존 패턴을 바꿔 동기화를 도움비트 수를 늘리지 않음

블록 부호화는 나누기 → 대치 → 조합 순서다. 4B/5B는 4비트를 5비트로 바꾸므로 데이터 4개당 전송 비트가 1개 늘어난다. 예를 들어 데이터율 80Mbps는 다른 오버헤드가 없을 때 부호화 후 100Mbps가 된다. 퀴즈에는 0000→11110이라는 대치 예가 있다.

PCM: 표본화 → 양자화(강의의 계수화) → 부호화
① 일정 시간마다 높이를 읽는다. ② 읽은 높이를 허용된 대표값으로 맞춘다. ③ 대표값을 0·1 비트열로 표현한다.

최고 주파수가 fmax인 신호를 강의의 나이퀴스트 표본화 조건으로 다루면 fs≥2fmax다. 표본당 nb비트, 채널 수 c이면 PCM 비트율은 R=fs×nb×c. 양자화 단계가 2ⁿᵇ개일 때 표본당 nb비트가 필요하다.

강의 예 음성 0~4kHz, 표본당 8비트, 1채널: fs=8,000표본/s → R=64,000bps. 퀴즈 예 최고 20kHz, 16비트, 스테레오 2채널: 40,000×16×2=1,280,000bps.

강의 p.45의 최소 PCM 대역폭 Bmin=nb×Banalog는 저대역 아날로그 입력을 최소 표본화하고 이진 디지털 전송을 가정한 관계다. 델타 변조(DM)는 PCM의 복잡도를 줄이기 위해 직전 표본과의 변화 방향·차이를 이용한다.

헷갈림 바로잡기

UNIT 08

변조: 진폭·주파수·위상 바꾸기

이번 단원에서 배우는 것 · 변조 파형의 변화 요소를 찾는다 / 대역폭 공식을 적용한다

변조는 데이터를 보내기 좋게 반송파의 특성을 바꾸는 일이다. 이해를 위한 예시: 높낮이가 아니라 소리의 크기로 신호를 약속하면 진폭을, 떨리는 빠르기로 약속하면 주파수를 바꾸는 셈이다.

입력 데이터기술반송파에서 바뀌는 특성
디지털ASK (Amplitude Shift Keying)진폭; OOK는 켜짐/꺼짐
디지털FSK (Frequency Shift Keying)주파수; BFSK는 두 주파수
디지털PSK (Phase Shift Keying)위상
디지털QAM (Quadrature Amplitude Modulation)진폭 + 위상
아날로그AM / FM / PM각각 진폭 / 주파수 / 위상

ASK/AM은 둘 다 진폭을 바꾸지만 입력이 다르다. ASK는 디지털 값에 따라 정해진 진폭으로, AM은 아날로그 정보 신호의 변화에 맞춰 진폭을 바꾼다. PSK는 경계에서 위상이 뒤집히는지, FSK는 같은 시간 안에 진동 횟수가 달라지는지 살핀다.

강의 대역폭 식기호와 적용
ASK·PSK: B=(1+d)SS: 신호율(초당 신호 요소), 0≤d≤1
FSK: B=(1+d)S+2Δf2Δf: 두 반송파 주파수의 차이
AM: BAM=2BB: 원래 아날로그 신호 대역폭
FM·PM: Bmod=2(1+β)B강의의 식; β를 문제 조건에 맞게 사용

이해를 위한 예시 S=2,000, d=0.5인 ASK: B=1.5×2000=3kHz. 같은 조건의 FSK에서 두 주파수 차이가 4kHz이면 B=3+4=7kHz. AM에서 원 신호 대역폭 4kHz라면 변조 후 8kHz다.

여러 상태를 구별하면 하나의 신호 요소로 여러 비트를 표현할 수 있다. M개의 구별되는 상태가 2의 거듭제곱이면 요소당 log₂M비트다. QAM은 진폭과 위상을 조합한다. 여기서는 첨부 강의·퀴즈에 나온 원리까지만 다루고 성상도 설계 문제는 확장하지 않는다.

헷갈림 바로잡기
신호율 S와 비트율 R을 항상 같다고 두지 않는다. 한 신호 요소가 b비트를 표현하면 R=bS다. 예제 파일의 구체적인 회선 부호 파형(NRZ·AMI·B8ZS 등)은 현재 강의에서 규칙이 제시되지 않아 예상문제에서 제외했다.

프레임과 채우기: 경계 지키기

이번 단원에서 배우는 것 · DLC·MAC을 구별한다 / 바이트·비트 채우기를 직접 한다

비트열을 끝없이 보내면 어디까지가 한 덩어리인지 알기 어렵다. 데이터 링크층은 비트들을 프레임으로 묶는다. 링크는 인접한 노드 사이 구간이고, 노드는 여기서 호스트나 라우터다.

개념역할
점-대-점 링크두 장치가 전용 사용

고정 길이는 길이로 경계를 계산할 수 있다. 가변 길이는 시작·끝을 구별하는 표시가 필요하다. 그런데 데이터 자체가 그 표시와 같으면 경계로 오인한다. 채우기(stuffing)는 이를 피하도록 송신자가 표시용 값을 추가하고 수신자가 제거하는 방법이다.

방법송신 측수신 측
문자(바이트) 중심데이터의 Flag와 ESC 앞에 ESC 추가데이터 영역의 ESC를 해석해 원래 바이트 복원
비트 중심데이터에서 연속 1이 5개면 즉시 0 삽입연속 1 다섯 개 다음의 삽입 0 제거
비트 채우기 · 이해를 위한 예시
원본: 01111110
전송 데이터: 011111010
플래그와 같은 원본을 데이터로 보낼 때, 연속된 1 다섯 개 뒤에 0을 넣어 플래그와 구별한다. 실제 프레임 경계용 플래그는 그대로 둔다.

바이트 예시 원본 데이터가 A Flag ESC B이면 채운 데이터는 A ESC Flag ESC ESC B다. 원래 ESC도 보호해야 하므로 ESC 앞에도 ESC를 붙인다.

오류 검출·해밍거리·패리티

이번 단원에서 배우는 것 · 검출과 정정을 구분한다 / 최소 해밍거리와 검출 보장을 연결한다

수신한 데이터가 틀렸는지 확인하려면 원래 데이터 외에 확인용 정보가 필요하다. 이것이 중복 비트다. 오류 검출은 “틀림을 알아챔”, 오류 정정은 “올바른 값으로 복원함”이다.

개념정의·규칙
단일 비트 오류한 비트만 뒤집힘
폭주 오류첫 오류부터 마지막 오류까지의 구간으로 길이를 셈
데이터워드원래 k비트 데이터
코드워드중복 r비트를 추가한 n=k+r비트
유효/무효 코드정해진 부호화로 만든 코드 / 그 밖의 비트열

k비트 데이터워드는 2ᵏ개다. n비트 패턴은 총 2ⁿ개지만 일대일 블록 부호화의 유효 코드워드는 2ᵏ개이고, 사용하지 않는 패턴은 2ⁿ−2ᵏ개다. 오류로 다른 유효 코드가 되면 검출에 실패할 수 있다.

★★★ 제작자 선정 학습 핵심
해밍거리 = 두 워드에서 서로 다른 자리 수 = XOR 결과의 1 개수.
최소 해밍거리 dmin인 코드가 모든 경우 검출을 보장하는 최대 오류 비트 수 = dmin−1. s개까지 보장하려면 dmin≥s+1.

강의 예 10101 XOR 11110=01011이므로 거리 3. 모든 유효 코드 쌍의 거리 중 최솟값이 dmin이다. 선형 블록 코드는 두 유효 코드의 XOR도 유효 코드가 된다. 이 경우 0이 아닌 코드워드에서 최소 1의 개수로 dmin을 구할 수 있다.

짝수 패리티는 코드워드의 1 개수를 짝수로 맞춘다. 데이터 1011의 1은 3개이므로 뒤에 1을 붙여 10111. 한 비트 또는 홀수 개가 뒤집히면 짝·홀이 바뀌어 검출된다. 짝수 개가 뒤집히면 짝·홀이 유지되어 놓친다. dmin=2이므로 모든 경우 보장 범위는 1비트까지다.

📝 LECTURE NOTE 제3장 p.23: 검출 코드는 설계된 오류만 검출한다. p.25의 강조식은 “모든 경우 보장”을 읽는 것이 핵심이다.
헷갈림 바로잡기
패리티 검사를 통과해도 오류가 없음을 보장하지 않는다. 제3장 p.15의 “연속적인 비트”는 p.16 그림과 함께 해석해야 한다. 폭주 구간 안의 모든 비트가 뒤집혀야 하는 것은 아니다. p.20의 2ⁿ은 가능한 패턴 수이지 유효 코드 수가 아니다.

CRC 계산을 끝까지 따라가기

이번 단원에서 배우는 것 · XOR 나눗셈을 수행한다 / 검사 결과의 한계를 설명한다

CRC(순환 중복 검사)는 송수신자가 같은 제수를 정해 두고 나눗셈의 나머지로 오류를 확인한다. 보통의 십진 나눗셈처럼 빌림을 하지 않고 비트별 XOR를 사용한다.

송신 과정
① 제수가 r+1비트이면 데이터 뒤에 0을 r개 추가한다.
② 제수로 모듈로-2 나눗셈한다. 1⊕1=0, 1⊕0=1, 0⊕0=0.
③ 원래 데이터 뒤에 r비트 나머지를 붙여 코드워드를 만든다.
수신 과정: 전체 코드워드를 같은 제수로 나누어 나머지를 검사한다.

강의 예: 데이터 1001, 제수 1011 (제수 4비트 → 나머지 3비트)

단계전체 작업 비트열판단
0 추가1001000뒤에 000을 붙임
왼쪽 첫 1에서 XOR00100001001 XOR 1011=0010
다음 첫 1에서 XOR0000110정렬한 제수로 계속 XOR
나머지110마지막 3자리
코드워드1001110원래 1001 + 나머지 110

수신자는 1001110을 1011로 나누어 000을 얻는다. 1000110으로 손상된 강의 예는 나머지 011로 오류를 검출한다. 나머지 0은 “검사에 걸리지 않음”이지 모든 오류가 없다는 증명은 아니다.

구분기억할 것
순환 코드유효 코드워드를 순환 이동해도 유효 코드워드
CRC-r검사 비트 r개, 생성다항식 차수 r, 이진 제수 r+1비트
강의 표의 적용 예CRC-8: ATM header / CRC-10: ATM AAL / CRC-16: HDLC / CRC-32: LAN
장점여러 오류 유형 검출에 우수, 하드웨어·소프트웨어 구현 용이

표 3.3의 C(7,4)는 최소 해밍거리 3이므로 최대 2비트 오류까지 모든 경우 검출 보장이다. 이를 임의의 CRC가 모두 같은 보장 성능을 갖는다고 확대하지 않는다. 검사합은 p.41에서 소개만 하므로 계산법은 범위에 추가하지 않는다.

헷갈림 바로잡기
Q3 p.4는 원래 캡처와 채팅 정정 내용이 다르다고 명시한다. 데이터 111111·제수 1010으로 직접 XOR 나눗셈하면 나머지 110이며, 정정본의 코드워드 111111110과 일치한다. 풀이 p.7의 “폭주” 표현과 비트 오류 개수에 대한 dmin 보장은 구별한다.

HDLC와 PPP의 구조

이번 단원에서 배우는 것 · 모드·프레임·제어 필드를 구별한다 / PPP의 보조 프로토콜을 연결한다

프레임을 어떻게 만들고 제어할지 실제 규칙으로 정한 것이 링크 프로토콜이다. HDLC는 비트 중심, 이 강의의 PPP는 문자(바이트) 중심이다.

HDLC 항목의미
NRM 정규 응답 모드불균형: 주국이 명령, 종국이 응답; 점-대-점·다중점
ABM 비동기 균형 모드균형: 양쪽 모두 주국·종국 역할; 점-대-점
I-프레임사용자 데이터 + 피기배킹 제어 정보
S-프레임피기배킹 부적절 시 흐름·오류 제어
U-프레임링크 자체 관리; 5비트로 32종류 구분

기본 필드 Flag → Address → Control → Information(프레임 종류에 따라) → FCS → Flag. Flag=01111110, FCS는 2/4바이트 CRC 오류 검출 필드다. 제어 필드 시작 비트로 I는 0, S는 10, U는 11을 구분한다.

HDLC 제어 정보읽는 방법
N(S)보내는 프레임의 순서 번호
N(R)수신 기대/확인응답 번호; RR에서 3이면 2번까지 수신, 3번 대기
P/FPoll: 주국→종국 / Final: 종국→주국
S Code 00 / 10RR 수신 준비 / RNR 수신 불가
S Code 01 / 11REJ 거부 / SREJ 선택적 거부

PPP(Point-to-Point Protocol)는 점-대-점 연결에 사용한다. Flag, Address(11111111), Control(00000011), Protocol, Payload, FCS, Flag로 구성한다. Protocol 필드가 실린 정보의 종류를 식별한다. 주소·제어 상수와 실제 프로토콜 종류를 혼동하지 않는다.

PPP 내부 역할프로토콜
링크 설정·유지·구성·해제LCP
사용자 신원 확인AP: PAP 또는 CHAP
네트워크층 프로토콜 협상·설정NCP; IP에 대해서는 IPCP

PPP 천이는 Dead → Establish → (선택적 Authenticate) → Network → Open(데이터 전달) → Terminate → Dead로 읽는다. 다중링크 PPP는 하나의 논리적 PPP 데이터를 여러 채널로 나눠 보낼 수 있다.

헷갈림 바로잡기

ALOHA: 먼저 보내고 확인하기

이번 단원에서 배우는 것 · 순수·틈새 ALOHA를 비교한다 / 취약시간과 백오프를 계산한다

공유 링크에서 여러 지국이 동시에 보내면 프레임이 충돌할 수 있다. 임의접근(Random Access)은 고정 시간표나 중앙의 순번 승인 없이, 각 지국이 정해진 절차에 따라 전송을 결정하는 경쟁 방식이다.

순수 ALOHA는 보낼 프레임이 있으면 매체를 미리 감지하지 않고 보낸다. 정해진 시간 안에 ACK가 없으면 실패로 보고 임의의 시간을 기다린 뒤 재시도한다. 모두 동시에 재전송하면 다시 충돌할 수 있으므로 랜덤 대기가 필요하다.

취약시간이란? 다른 프레임의 시작 때문에 내 프레임과 겹칠 수 있는 시간 범위다. 순수 ALOHA에서는 내 전송 시작 t를 기준으로 t−Tfr부터 t+Tfr까지 2Tfr가 위험하다. 틈새 ALOHA는 같은 슬롯에서 시작한 프레임끼리 충돌하므로 Tfr로 줄어든다.

프레임 200bit, 링크 200kbps → Tfr=1ms.
순수 취약시간 2ms / 틈새 취약시간 1ms.
슬롯을 사용해도 같은 슬롯에 두 지국이 보내면 충돌한다.

백오프 실패 후 K회째이면 난수 R을 0~2ᴷ−1 중에서 고른다. 강의 p.62는 TB=R×Tp 또는 R×Tfr를 제시하므로 문제에 지정한 기준시간을 사용한다. 예: 거리 600km, v=3×10⁸m/s → Tp=2ms. K=3, Tp 기준이면 최대 대기=(8−1)×2=14ms. K=1의 즉시 재시도 확률은 R=0일 확률 1/2이다.

UNIT 15

CSMA·충돌 검출·충돌 회피

이번 단원에서 배우는 것 · 지속 방식을 비교한다 / 최소 프레임과 최대 거리를 계산한다

CSMA는 “말하기 전에 듣기”다. 매체가 사용 중인지 감지한 후 전송한다. 그래도 먼 지국이 보낸 신호가 아직 도착하지 않으면 빈 회선처럼 보여 충돌할 수 있다. 원인은 전파 지연이다.

지속 방식회선이 비어 있으면사용 중이면
1-지속즉시 전송계속 감지하다 비면 전송
비지속즉시 전송임의 시간 후 다시 감지
p-지속확률 p로 전송; 1−p로 다음 슬롯까지 대기프로토콜에 따라 감지·재시도

CSMA의 취약시간은 최대 전파시간 Tp다. CSMA/CD는 전송 중에도 매체를 관찰하고, 충돌 시 전송을 중단하고 충돌 신호를 알린 뒤 백오프·재시도한다. 강의 p.77의 “전송한 뒤” 표현은 p.78·80의 전송 중 검출 흐름과 함께 읽는다.

★★★ 제작자 선정 학습 핵심
Tfr≥2Tp → Nmin=2RTp → dmax=Nv/(2R)
N: 프레임 비트 수, R: bps, v: m/s, Tp=d/v.
가장 먼 곳에서 충돌 소식이 되돌아올 때까지 송신 중이어야 하므로 왕복 2Tp를 확보한다.

강의 예 R=10Mbps, Tp=25.6μs이면 최소 Tfr=51.2μs → Nmin=10⁷×51.2×10⁻⁶=512bit=64byte.

거리 계산 64byte=512bit, v=2×10⁸m/s, 다른 지연을 무시하면 10Mbps: 5120m, 100Mbps: 512m, 1Gbps: 51.2m. 최소 프레임이 같으면 전송률이 100배일 때 허용 거리는 1/100배다.

강의는 에너지 준위를 휴지 0, 정상 전송, 충돌 시 비정상 증가로 설명한다. p.82의 처리율 비교(1-지속 약 50%, 비지속 최대 약 90%)는 제시된 모델의 값이며 모든 네트워크의 고정 보장값은 아니다. 전통적인 10Mbps 이더넷은 1-지속 CSMA/CD로 소개된다.

CSMA/CA는 Collision Avoidance, 무선 LAN용 충돌 회피다. 범위 마지막인 p.83은 이름·목적만 소개하므로 이후 장의 상세 동작은 출제하지 않는다.

헷갈림 바로잡기
풀이 p.16의 512/100Mbps는 51.2μs가 아니라 5.12μs다(최종 512m는 맞음). 3장 p.76의 백오프 상한 2ᴺ×최대 전송시간과 p.80의 정수 난수 0~2ᴷ−1 표기가 다르다. 계산 문제에는 사용할 식을 명시한다.

빠른 검산 예시

5.12μs의 절반은 2.56μs.
2×10⁸m/s × 2.56μs = 512m.
