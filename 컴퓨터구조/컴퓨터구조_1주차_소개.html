수업 개요

현대 컴퓨터가 안에서 어떻게 동작하는지를 배웁니다.

  • 컴퓨터 내부 구조를 이해하면 더 나은 코드를 쓰게 됩니다. 같은 알고리즘이라도 하드웨어가 어떻게 동작하는지 알면 훨씬 빠른 코드를 작성할 수 있습니다.
  • MIPS 프로세서 구조를 중심으로 다룹니다. 구조가 단순하고 규칙적이어서, 프로세서가 명령어를 처리하는 과정을 끝까지 따라가 볼 수 있습니다.
  • MIPS 어셈블리 언어를 직접 실습합니다. 고급 언어 한 줄이 기계 수준에서 어떤 명령어로 바뀌는지 손으로 확인합니다.

실습 도구

두 가지 오픈소스 시뮬레이터를 사용합니다. 둘 다 무료로 내려받아 개인 노트북에 설치할 수 있습니다.

QtSPIM

MIPS 어셈블러 시뮬레이터

어셈블리 코드를 한 줄씩 실행하면서 레지스터와 메모리 값이 어떻게 바뀌는지 눈으로 확인합니다.

명령어 단위 실행 · 레지스터 관찰 · 메모리 덤프

Logisim

논리 회로 시뮬레이터

게이트부터 시작해 ALU, 레지스터 파일, 제어 유닛을 직접 연결하고 MIPS 프로세서를 완성해 봅니다.

회로 설계 · 클럭 구동 · 동작 검증

왜 컴퓨터 구조를 배우나

소프트웨어를 잘 만들기 위해서입니다. 아래는 그중 눈에 띄는 네 가지입니다.

성능을 진짜로 끌어올리려면

캐시와 메모리 계층, 분기 예측, 파이프라이닝, SIMD와 GPU 같은 실제 병렬성을 알아야 코드와 모델을 최적화할 수 있습니다.

SoA vs AoS · 루프 타일링 · 벡터화 · 메모리 대역폭

보안의 뿌리가 여기 있습니다

버퍼 오버플로우, 권한 수준, 캐시 타이밍 같은 부채널 공격은 모두 하드웨어 구조에서 출발합니다. 안전한 코드를 설계하려면 필수입니다.

스택 프레임 · 권한 링 · 측면 채널

병렬·분산 프로그래밍의 토대

코어와 스레드, 메모리 일관성, 원자적 연산을 모르면 데이터 레이스와 성능 역행을 겪게 됩니다.

코어 · 워프 · 메모리 일관성 · 원자적 연산

상위 과목으로 이어집니다

운영체제의 가상메모리와 컨텍스트 스위칭, 컴파일러의 레지스터 할당, 데이터베이스의 메모리 레이아웃까지 이해가 달라집니다.

OS · 컴파일러 · 데이터베이스 · 네트워킹

왜 컴퓨터 구조를 배우나

그리고 지금 산업이 움직이는 방향과 맞닿아 있는 세 가지입니다.

클라우드와 엣지의 비용·전력

x86과 ARM의 차이, NUMA, 가상화, 전력 곡선을 이해하는 것이 성능과 원가, 전력을 두고 내리는 의사결정의 핵심입니다.

x86 vs ARM · NUMA · 가상화 · DVFS

AI·그래픽스 가속기의 실전 활용

GPU와 TPU, NPU의 스레딩·메모리 모델, 텐서 코어 특성, 양자화와 메모리 발자국이 추론 속도와 지연을 좌우합니다.

텐서 코어 · 양자화 · 메모리 발자국

새로운 아키텍처를 읽는 힘

RISC-V, 특수목적 가속기, PIM처럼 빠르게 바뀌는 하드웨어 흐름을 읽고 소프트웨어 전략을 세울 수 있게 됩니다.

RISC-V · 도메인 특화 가속기 · PIM
